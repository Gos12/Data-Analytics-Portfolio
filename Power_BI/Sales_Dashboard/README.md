# Sales Performance Dashboard | Microsoft Power BI

## Project Overview

This project presents an interactive Sales Performance Dashboard developed using Microsoft Power BI.

The objective is to analyze sales performance, identify trends, compare year-over-year results, and explore the contribution of different product categories and subcategories.

## Business Questions

The dashboard was designed to answer the following questions:

- How are sales performing over time?
- How have sales changed compared to the previous year?
- Which product categories and subcategories generate the highest sales?
- How does sales performance vary across different product categories?
- Does marketing spending influence sales? 
- Are certain marketing campaigns more efficient than others?

## Tools & Technologies

- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Power Query
- Data Modeling
- Data Visualization

## Key Features

- Interactive dashboard with category slicers
- Year-over-year sales comparison
- Dynamic visualizations
- Sales performance KPIs
- Category and subcategory analysis with product level drill-down capabilities
